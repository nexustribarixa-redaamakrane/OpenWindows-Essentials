# OpenWindows Networking Stack

## Layer Architecture
``nApplication Layer  : owsock64, owtls64
Transport Layer    : tcpcore, udpcore
Network Layer      : ipstack, pfwall
Link Layer         : e1000, rtl8139, virtio_net
``n
## Services
- DHCP Client (dhcpcli)
- DNS Resolver (dnscli)
- Packet Filter Firewall (pfwall)
