Properties

Every codepoint’s machine-readable attributes.

Properties are stored in Props/PropList.txt and the derived tables under Derived/. The starter set for 0.1.0:

Property Scope Meaning
Unicode_Bridged 0x000000–0x10FFFF Value is 1:1 with Unicode
Control_Plane 0x110000–0x11FFFF Member of the SCP
Diagnostic_BAN / WARN / COM / SOFT BANcode registry blocks Member of a diagnostic registry block
Printable 0x120000–0x7FFFFFEF Advances the cursor
Trap_Instruction 0x7FFFFFF0–0x7FFFFFFE Raises the stream into diagnostics
Sentinel_Value 0x7FFFFFFF End-of-stream marker

Derived properties

Derived tables close the property set over rules, mirroring Unicode’s DerivedCoreProperties. 0.1.0 derives Alphabetic over the compatibility and native spaces and Control over the SCP and traps.

In the database: sucd/Props/PropList.txt and sucd/Derived/DerivedCoreProperties.txt.
