News

  • 2026-08-14 — The full multi-page website launches, mirroring the structure of unicode.org, with repository directory listings for every module.
  • 2026-08-14 — SuperUnicode 0.1.0 released: Base and Extended /Public trees, plugin subsystem with boot-time checksum gate, OWFS-only plugin partitions, SDK with template and hellocp example.
  • 2026-08-14 — The plugin pipeline is verified end-to-end: plugin_pack → plugin_verify passes the hellocp blob through the exact checksum gate the boot loader runs.
  • 2026-08-26 — The SUST serialization module lands: SUTF-16 gains explicit big-endian (canonical) and little-endian byte-order transports (sust16), the SUST fixed-width and e-SUST IPC families complete the byte layer, and SUTF-16 is documented surrogate-free. Framing (sutf) and serialization (sust) are now separate modules.
  • Coming in 0.2.0 — first native allocations, SCP registry assignments, and additional SUTR reports.
